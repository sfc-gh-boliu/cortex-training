# Evaluate Reinforcement Learning

The [Math GRPO example](../../../examples/rl/README.md#evaluation-and-logs)
reports reward, answer correctness, format compliance, truncation rate, and
completion length on held-out MATH-500 problems, as `test/env/all/*` metrics.

Pass@k reporting, task-specific success metrics, confidence intervals, and
reusable evaluator interfaces are still planned.
